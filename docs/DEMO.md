# Demo Runbook

## Demo Fixtures
Use two original synthetic courses. Include known dates, an undated assignment, an assessment, policy text, office hours, a missing instructor email, and one repeated assessment mention. Include a separate conflict fixture for competing dates. Label all fixtures as synthetic demo courses.

## Three-Minute Flow
1. Explain the problem of scattered course information.
2. Upload two EPUBs and show measured processing stages.
3. Show the combined course and deadline dashboard.
4. Open a deadline's source evidence and an undated item.
5. Ask a supported policy question and open its citation.
6. Ask for missing professor contact information and show abstention.
7. Explain deterministic parsing, Nemotron extraction, validation, and limitations.
8. Report measured fixture results honestly.

## Rehearsal Checklist
Use a fresh session, valid consent and timezone, live-mode labeling, the correct two fixtures, readable source evidence, unknown/conflict states, supported and unsupported questions, deletion, and a working local production build. Record actual latency rather than promising it.

## Failure Handling
If NVIDIA is unavailable, show a clearly labeled previously processed result or recording and say the provider is unavailable. Do not silently replace live AI with static answers. If a file is malformed, show its safe rejection when useful. If hosting fails, return to the local demo.
